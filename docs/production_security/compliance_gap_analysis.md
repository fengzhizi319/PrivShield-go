### 3.1 密码算法合规性

| 密评要求项 | 状态 | 说明 |
|---|---|---|
| **身份鉴别应采用国密算法** | ⚠️ | TLCP 应用层已支持 SM2 证书；控制台 JWT 使用 HMAC-SHA256（非国密）；mTLS 仍使用 RSA/ECDSA 证书（部署层待替换为 SM2） |
| **数据传输机密性应采用国密算法** | ✅ | `pkg/tlsutil/tlcp.go` 国密 TLCP，SM4 密码套件；全部 4 个服务 HTTP 入口已接入 |
| **数据传输完整性应采用国密算法** | ✅ | 审计链 HMAC-SM3，存证完整性校验 SM3 |
| **数据存储机密性应采用国密算法** | ✅ | `pkg/crypto/sm4.go` SM4-128（GB/T 32907-2016），SM4-GCM 信封加密 |
| **数据完整性保护应采用国密算法** | ✅ | `pkg/crypto/sm3.go` SM3（GB/T 32918.4-2016），审计链 HMAC-SM3 |
| **数据原点抗抵赖应采用国密算法** | ✅ | SM2 数字签名已接入审计写入/核验/快照验真全流程 |
| **SM2 椭圆曲线公钥密码算法** | ✅ | `pkg/crypto/sm2.go` 纯 Go SM2 签名/验签/加密/解密；审计存证全流程已调用 |

### 3.2 密钥管理生命周期

| 密评要求项 | 状态 | 说明 |
|---|---|---|
| **密钥生成** | ✅ | `crypto/rand.Reader` 生成安全随机 salt 与 nonce |
| **密钥存储** | ⚠️ | 环境变量注入，运行期内存明文存储。缺少 HSM/KMS 集成 |
| **密钥分发** | ⚠️ | 环境变量注入各实例。KeyStore 支持文件热重载（5s 轮询 + 原子替换） |
| **密钥使用** | ✅ | SM4-GCM 每次加密独立 salt 派生密钥；HMAC-SM3 密钥化前映像 |
| **密钥更新/轮换** | ✅ | `pkg/crypto/envelope.go` 多版本密钥注册表已接入 `EncryptString/DecryptString`：加密写入活跃版本（v3 格式），解密按版本查找。`RegisterKeyVersionsFromEnv()` 从 `PRIVACY_CRYPTO_KEY_<VERSION>` 注册多版本 |
| **密钥备份与恢复** | ❌ | 无备份机制，丢失加密密钥则已加密数据不可恢复 |
| **密钥销毁** | ❌ | 无安全销毁/内存清零机制 |
| **密钥生存期管理** | ⚠️ | API Key 支持 `expires_at`；多版本注册表支持轮换过渡期。缺少自动过期告警 |

## 5. 待推进事项

### 代码层差距（❌）

| 差距 | 说明 | 建议 |
|---|---|---|
| MAC 强制访问控制 | 当前为 DAC，3-Layer 分类结果不驱动访问控制 | 将分类分级结果接入访问控制决策链路 |
| 运行时完整性校验 | 无代码签名/运行时哈希 | 容器镜像签名、启动时二进制校验 |
| 集中安全策略平台 | 配置分散在各环境变量 | 统一策略下发、版本控制、回滚 |
| 密钥备份与恢复 | 丢失加密密钥则数据不可恢复 | 接入 KMS/HSM 或加密备份方案 |
| 密钥安全销毁 | 无内存清零机制 | 评估 `mlock` + 显式清零方案 |
| 硬件密码模块 | 纯软件实现 | 接入 HSM 或云密码模块 |

### 部署层差距（⚠️ 代码就绪，需部署配置）

| 差距 | 说明 | 建议 |
|---|---|---|
| SM2 证书部署 | TLCP 代码已就绪，需生成 SM2 证书 | 配置 `PRIVACY_TLS_NATIONAL_CIPHER=true` + `PRIVACY_TLCP_*` 证书路径 |
| SIEM 对接 | Prometheus 告警已就位 | 对接 Splunk/ELK，建立事件关联分析 |
| HSM/KMS 集成 | 密钥以环境变量存储 | 接入 HashiCorp Vault / 云 KMS |
| JWT Access Token 缩短 | 当前默认 24h | 缩短至 30min + Refresh Token |
| 分布式登录锁定 | 当前为进程内存级 | 迁移至 Redis 支持多实例共享 |
| 安全审计报表增强 | 当前为简单统计 | 增加安全事件关联分析与合规报表 |
